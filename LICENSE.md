# 덱별 오버라이드

* 각 덱의 저작권은 그 덱의 저자에게 있다. 저자는 덱 `README.md` 의 `## 라이선스` 절에 다른 라이선스를 지정할 수 있다
    - ex) [decks/misc/RamyeonCooking](decks/misc/RamyeonCooking/README.md) — CC BY 4.0
* 덱 `README.md` 에 라이선스가 **없거나 자리표 그대로**면 위 기본값이 적용된다. 라이선스를 명시하지 않고 Pull Request 로 덱을 기여하면 기본값에 동의한 것으로 본다
* 덱 안에서 인용한 제3자 자료(외부 이미지 등)는 원 저작자의 라이선스를 따른다 — 덱 `README.md` 나 슬라이드에 출처를 적는다
