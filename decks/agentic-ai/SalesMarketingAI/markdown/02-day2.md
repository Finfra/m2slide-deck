### 마크다운 문법 ② — 링크·이미지·코드 블록
#layout-contents
#id-markdown-syntax-2

| 적는 법                       | 미리보기에서 보이는 모양              |
| :---------------------------- | :------------------------------------ |
| `[핀프라](https://finfra.kr)` | 누르면 열리는 링크 «핀프라»           |
| `![로고](img/logo.png)`       | 그 자리에 그림이 보임                 |
| 백틱 하나로 감싼 낱말         | 회색 바탕의 짧은 코드 — 단축키·파일명 |
| 백틱 세 개로 위아래를 감싼 줄 | 서식 없이 그대로 보이는 코드 블록     |

* 이 교안의 프롬프트 상자가 코드 블록임. 상자 안 글은 기호가 있어도 모양으로 바뀌지 않음.
* 링크·이미지는 대괄호 다음에 소괄호를 붙임 — 이미지는 맨 앞에 느낌표가 하나 더 붙음.

### 마크다운 문법 ③ — 표는 세로선 한 줄이 한 행임
#layout-contents
#id-markdown-table-syntax

::: htmlart annotate
* target: | :-- | :-- | --: |
* over yellow: | → 열을 가르는 세로선
* under blue: :-- → 왼쪽 정렬
* under green: --: → 오른쪽 정렬
:::

```text
| 제조사 | 제품 | 정하중 | 동하중 | 단위 |
| :-- | :-- | --: | --: | :-- |
| GGB | DU | 250 | 140 | N/mm² |
```

* 세로선(`|`)이 열을 가르고, 둘째 줄이 머리글 구분선임.
* `:--` 는 왼쪽 정렬, `--:` 는 오른쪽 정렬임.
* ChatGPT 가 코드 블록에 낸 마크다운 표를 복사 버튼으로 붙이면 이 형식이고, VSCode 미리보기에서 표로 보임. 화면의 표를 끌어 복사하면 이 형식이 되지 않음.

### 조사용 AI 는 두 부류 — 검색 결합형과 대화형
#layout-contents
#id-two-types-research-ai

| 구분        | 검색 결합형                                | 대화형                                     |
| :---------- | :----------------------------------------- | :----------------------------------------- |
| 답하는 방식 | 질문마다 웹을 검색해 출처 링크를 달아 답함 | 학습한 지식으로 답하고 출처가 없을 수 있음 |
| 쓸 때       | 최신 동향과 수치를 찾을 때 씀              | 개념 설명과 문장 다듬기에 씀               |

* Perplexity 는 검색 결합형이고 계정 없이 열림. 기본 검색은 무료로 넉넉하고, 고급 검색·심층 조사·첨부는 무료 한도가 적음.
* 같은 질문도 부류에 따라 답의 근거가 달라짐. 검색 결합형도 링크가 틀릴 수 있어 링크를 열어 확인함.
