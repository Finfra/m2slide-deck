# 주제

영업·마케팅 담당자가 **조사·제안·콘텐츠·해외영업·고객 데이터를 생성형 AI 로 만들고 보내고 올리는** 6일 24시간 과정. 마지막 성과물은 *"우리 부서 영업·마케팅 과제 1건을 자동화"* 하는 과제 카드다.

# 청중

**제조기업 영업·마케팅 실무자**(국내영업·해외영업·마케팅·고객 응대). 전제 지식은 영업 실무이고 **코딩 경험은 없으며, 도구 숙련도는 개발 인접 직군보다 낮다고 본다.**

* 🔴 **수강생은 터미널 명령을 치지 않는다.** Codex 가 실행하고 수강생은 결과를 판정함
* 🔴 **자사 고객 리스트·견적·영업 데이터는 쓰지 않는다** — 보안 + 개인 구글 계정. 실습 데이터는 전부 가상·공개 자료
* 🔴 **배포 주소(Netlify)는 누구나 연다** — 가상·공개 자료만 올림
* 계정은 지급 ChatGPT + 각자의 개인 구글. Claude 계정은 없음
* 필드 영업은 PC 를 많이 쓰지 않으므로 📱 모바일·최소 조작 경로를 PC 단계마다 병기한다

# 분량

**1,440 분** (하루 4시간 × 6회, 50분/10분 × 4교시)

# 스타일

**강의** — 3인칭 · `~함`/`~임` 줄임체 · 금지어 여러분·오늘·Let's

# 학습 목표

* 제조 B2B 영업·마케팅 업무에 맞춘 **프롬프트 6요소와 맥락 카드**로 AI 에 일을 시킨다
* 시장·고객·경쟁사 조사를 **출처와 함께** 받고, 틀린 곳을 가려낸다
* 상담 메모에서 **페인포인트를 표로 뽑고**, 제안서·견적 회신을 문서(`.docx`)로 만든다
* 제품 소개 시안을 **홈페이지로 만들어 배포**하고 SNS 글에 링크를 건다
* 슬라이드·이미지·사진 일괄 처리를 도구별 한계를 알고 고른다
* 영문 메일·번역·엑셀 CRM·n8n 으로 **해외영업과 리드 분류**를 돌리고, 우리 부서 과제 1건을 카드로 남긴다
* 매 실습(Hands-on)은 입력 파일·프롬프트·기대 결과를 따라 **처음부터 끝까지 직접 쳐서** 끝낸다

# 일차 구성

| 일차  | 주제                                    | 모션그래픽(mg)                         |
| :---- | :-------------------------------------- | :------------------------------------- |
| 1일차 | 생성형 AI 영업·마케팅 활용과 프롬프트   | `mg/00-flow`(전체 흐름) · `mg/01-day1` |
| 2일차 | 시장·고객·경쟁사 조사 자동화            | `mg/02-day2`                           |
| 3일차 | 영업 제안서·견적·페인포인트 분석        | `mg/03-day3`                           |
| 4일차 | 제품 콘텐츠·마케팅 자료 자동화          | `mg/04-day4`                           |
| 5일차 | AI 이미지·슬라이드·영상 콘텐츠          | `mg/05-day5`                           |
| 6일차 | 해외영업·고객 데이터 분석·CRM 자동화    | `mg/06-day6`                           |

과정 산출물은 6일에 걸쳐 한 줄로 이어진다: 맥락 카드 → 브리핑 → 제안서 → 홈페이지·CSV → 시각물·차트 → 영문·CRM·과제 카드. 앞날의 결과가 다음 날의 재료가 되므로 순서를 바꾸지 않는다.

* mg 는 일차 챕터 슬라이드 바로 뒤에 한 장씩 둔다. 1일차에는 6일 전체 흐름 장이 하나 더 있다
* mg 장면은 `mg/_src/` 의 공통 도구 + 장면 원본을 `node mg/_src/compose.js` 로 합쳐 `mg/NN-*/scene.js` 를 만든다(생성물은 직접 고치지 않음)
