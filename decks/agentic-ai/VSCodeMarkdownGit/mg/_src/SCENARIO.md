# VSCodeMarkdownGit mg 시나리오 (추가분 04~06)

* 대상: `VSCodeMarkdownGit.md` (single mode 원고)
* 판형: 4:3 (`slide_ratio: "4:3"`) — 캔버스 1600×1200, 30fps, 끝 화면에서 멈춤
* 테마: 기존 `mg/01-vscode`·`02-markdown`·`03-git` 와 같은 밝은 색 체계(흰 바탕 · 남색 글자 · 황색 강조) · 시스템 글꼴
* 원칙
    - 원고에 있는 문구·수치만 화면에 올림 — 새 주장 없음
    - `renderFrame(ctx, t)` 결정론 — `Math.random`·`Date`·`performance.now` 금지
    - 글자 잘림 방지 — 칸 안 글자는 `fit()` 이 칸 폭에 맞춰 크기를 줄임
    - 기존 01~03(챕터 오프닝)과 메시지가 겹치지 않게 고름
        + 01-vscode: 흩어진 파일 → 한 화면 / 02-markdown: 기호 → 사람·AI 가 같은 문서 / 03-git: 저장 지점·되돌리기·갈래·합치기
        + 추가분은 «덱 전체 흐름» · «세션 분리» · «기준 문서 사슬» 로, 위 셋이 다루지 않는 장을 맡음
* 공통 틀: 머리(칩 + 제목, 0.2~0.8초) · 아래 한 줄(장면 끝 2~3초 전)
* 합성: `node decks/agentic-ai/VSCodeMarkdownGit/mg/_src/compose.js` → `mg/NN-*/scene.js` (common.js 전문을 싣는 자급 파일)

## ⑥ 06-chain — 기준 문서 사슬

* 근거
    - «요구사항 → 설계 → 이슈 → 변경» (사슬로 이어지고 모두 Markdown 으로 남음 · 기준 문서가 있어야 이슈가 근거를 가짐)
    - «코드를 읽고 쓴 설계 문서의 함정» (기준 문서는 코드보다 먼저 있어야 함)
    - «작업 하나 = 이슈 하나» (이슈 하나 만들기 → 작업 → 저장 지점 남기기 → 이슈에 이어 두기)
* 화면 요소: 문서 노드 4개(요구사항 · 설계 · 이슈 · 변경)와 사이 화살표 · 첫 노드 위 «먼저» 깃발 · 설계 → 이슈 «근거» 꼬리표 · 이슈 아래 작업 → 저장 지점 3개 → «이슈에 이어 둠» 되돌아오는 선 · 네 노드를 감싸는 괄호 «모두 Markdown 으로 남음»
* 시간표
    - 0.2 머리
    - 1.0 / 1.8 / 2.6 / 3.4 노드 4개가 차례로 나타남, 사이 화살표가 이어 그어짐
    - 4.4 «요구사항» 위 «먼저 — 코드보다» 깃발
    - 5.2 설계 → 이슈 화살표에 «근거» 꼬리표 · 이슈 노드 테두리 강조
    - 6.2~8.2 이슈 아래 «작업 하나 = 이슈 하나» 줄 — 이슈 → 작업 → 저장 지점 3개(0.3초 간격) → 이슈로 되돌아오는 선
    - 9.0 네 노드 아래 괄호 «모두 Markdown 으로 남음»
