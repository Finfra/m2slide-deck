# fPmIntro 모션그래픽 시나리오

* 대상 덱: `decks/app/fPmIntro`(ko) · `decks/app/fPmIntro_en`(en) — 같은 장면을 두 언어로 함께 생성
* 비율: 두 덱 `_config.yml` 에 `slide_ratio` 미지정 → m2slide 기본 16:9 (1.7778) → 캔버스 **1920 × 1080**
* 규약: `renderFrame(ctx, t)` 결정론 — `Math.random`·`Date`·`performance.now` 금지, 모든 값은 시간 T 의 함수 · 시스템 글꼴만 · 끝 화면(DUR)에서 멈춤
* 원고 근거만 씀 — 각 장 «근거» 줄의 원고 절에 없는 기능·수치는 넣지 않음. 예시 데이터(폴더명 등)는 회색 막대·「A/B/C」 자리표시로 처리
* 문구: `TEXT.js` 한 곳(`TEXT.ko` · `TEXT.en`) — 장면 원본(`sNN-*.js`)에는 글자를 직접 쓰지 않음. 두 언어 키·배열 길이가 다르면 compose 가 멈춤

## 파일 구조

```
fPmIntro/mg/
├── _src/
│   ├── SCENARIO.md     # 이 문서
│   ├── TEXT.js         # 문구 표 — TEXT.ko / TEXT.en
│   ├── common.js       # 공통 그리기 도구 (1920×1080)
│   ├── s01-what.js … s06-start.js   # 장면 원본 (L.* 로 문구 참조)
│   └── compose.js      # 합성 → fPmIntro/mg/NN-*/scene.js(ko) + fPmIntro_en/mg/NN-*/scene.js(en)
└── 01-what/scene.js …  # 생성 파일 (직접 고치지 않음)
```

* 합성: `node decks/app/fPmIntro/mg/_src/compose.js`
